# Ian Mendoza: portfolio

A static site: one `index.html`, no build step, no dependencies.

## Deploy
1. Create a new GitHub repo and upload these files (or push them).
2. Go to vercel.com, then Add New > Project, and import the repo.
3. Framework Preset: **Other**. Leave Build Command and Output Directory empty. Click Deploy.
4. Share the **production** URL (the one ending in `.vercel.app`, or your custom domain).

## Before you share it
Replace the placeholder email and links in `index.html` (search for `example.com`).
